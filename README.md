# market
E-Commerce Platform (Spring Boot, Inventory & Procurement)

Легковесный мини-интернет-магазин и система управления запасами на платформе **Spring Boot**. Проект предоставляет REST API для полного цикла работы: от закупки товаров у поставщиков до продажи конечным клиентам с контролем остатков на складах.

## ✨ Функционал
* **Каталог товаров:** Управление номенклатурой, ценами и характеристиками.
* **Складской учёт (Inventory):** Контроль остатков на нескольких складах, перемещения и резервирование под заказы.
* **Управление закупками (Procurement):** Оформление заказов поставщикам, учёт поступления товаров и автоматическое увеличение остатков на складах при приемке.
* **Продажи и корзина:** Добавление товаров в корзину, валидация доступного количества и оформление заказов покупателей со списанием со складов.

## 🛠 Технологический стек
* **Framework:** Spring Boot 3.x (Spring Web, Spring Data JPA)
* **Язык разработки:** Java 17 / 21
* **База данных:** H2 (In-Memory) / PostgreSQL
* **Сборщик проекта:** Maven

## 📦 Быстрый запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd market
   ```

2. **Запустите приложение:**
   ```bash
   ./mvnw spring-boot:run
   ```
   Приложение будет доступно по адресу: `http://localhost:8080`

## 🔄 REST API Эндпоинты

### 🛍 Продажи и Склад

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| **GET** | `/api/products` | Получить список всех товаров |
| **GET** | `/api/warehouses/stock/{id}` | Проверить остатки товара на складах |
| **POST** | `/api/orders` | Оформить заказ покупателя (списание со склада) |

### 📦 Закупки (Поставщики)

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| **POST** | `/api/purchase-orders` | Создать заказ поставщику |
| **POST** | `/api/purchase-orders/{id}/receive` | Оприходовать товар на склад (приемка поставки) |
| **GET** | `/api/suppliers` | Получить список поставщиков |

### Пример запроса на закупку товара (POST `/api/purchase-orders`):
```json
{
  "supplierId": 5,
  "targetWarehouseId": 1,
  "items": [
    {
      "productId": 12,
      "quantity": 100,
      "purchasePrice": 450.00
    }
  ]
}
```
